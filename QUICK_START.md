# 🚀 QUICK START - Deploy in 5 Steps

## Step 1️⃣: GitHub Account
- Go to https://github.com/signup
- Sign up (takes 2 minutes)

## Step 2️⃣: Create Repository
- Go to https://github.com/new
- Name: `astronaut-reef`
- Choose **Public**
- Click **Create repository**

## Step 3️⃣: Upload Files
This folder (`/outputs/`) has everything you need:

**Essential files to upload:**
- `spaceship_simulator.jsx`
- `package.json`
- `public/index.html`
- `src/App.js`
- `src/index.js`
- `.gitignore`

**Easiest method:**
1. Click green **Code** button on GitHub
2. Click **Upload files**
3. Download all the files from this folder
4. Drag them into GitHub

Or ask me to create a ZIP file you can upload all at once!

## Step 4️⃣: Deploy to Vercel
- Go to https://vercel.com
- Click **Sign up** → **Continue with GitHub**
- Find `astronaut-reef` repo
- Click **Import** → **Deploy**
- Wait 2 minutes ⏳

You'll get a URL like: `https://astronaut-reef-xyz.vercel.app`

## Step 5️⃣: Add to iPad Home Screen
1. Open Safari on iPad
2. Go to your Vercel URL
3. Tap **Share** ↗️
4. Tap **Add to Home Screen**
5. Name it "Astronaut Reef"
6. Tap **Add**

Done! 🎉 He now has the app on his home screen.
