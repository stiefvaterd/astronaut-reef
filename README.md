# 🚀 Astronaut Reef - Spaceship Simulator

A toddler-friendly interactive spaceship game built with React. Explore space, launch rockets, and land on Mars!

## 📱 Deploy to Vercel (5 minutes)

Follow the step-by-step guide below to deploy this app so you can access it on any iPad, phone, or computer.

---

## 🔧 Step 1: Create a GitHub Account (if you don't have one)

1. Go to **https://github.com/signup**
2. Enter your email, create a password, choose a username
3. Click **Create account**
4. Verify your email (GitHub will send you a link)
5. Done! You now have a GitHub account.

---

## 📂 Step 2: Create a GitHub Repository

1. Go to **https://github.com/new**
2. Repository name: `astronaut-reef` (or any name you like)
3. Description: "Spaceship simulator for toddlers"
4. Choose **Public** (so Vercel can access it)
5. Check the box: **Add a README file**
6. Click **Create repository**

---

## 📤 Step 3: Upload Project Files to GitHub

Now you need to upload the project files. The easiest way is through GitHub's web interface:

### Using GitHub Web Interface (Easiest):

1. You're now on your new repository page
2. Click the green **< > Code** button on the right
3. Click **Upload files**
4. In a new browser tab, go to: **https://claude.ai/chat/[current-chat-url]**
   - Download these files from the outputs folder:
     - `spaceship_simulator.jsx`
     - `package.json`
5. Drag the downloaded files into the GitHub upload area (or click to select them)
6. At the bottom, click **Commit changes**
7. Now create the folders and additional files:

### Creating Folders and Files in GitHub:

8. Click **Add file** → **Create new file**
9. In the filename box, type: `public/index.html`
10. Copy and paste the content from the `public/index.html` file you have
11. Click **Commit new file**

12. Repeat for these files:
    - `src/App.js` (content provided below)
    - `src/index.js` (content provided below)
    - `.gitignore` (content provided below)

**If this seems complicated**, alternatively:
- Ask me to create a ZIP file with all files organized
- You can unzip it locally, then upload all at once

---

## 🌐 Step 4: Connect to Vercel and Deploy

1. Go to **https://vercel.com/signup**
2. Click **Continue with GitHub**
3. Authorize Vercel to access your GitHub account
4. Choose your account and click **Import Project**
5. Select the `astronaut-reef` repository
6. Vercel will auto-detect it's a React app
7. Click **Deploy**
8. Wait 1-2 minutes for it to build and deploy
9. You'll see a success message with a URL like: `https://astronaut-reef-xyz.vercel.app`

---

## 📱 Step 5: Use on iPad

1. On the iPad, open Safari
2. Go to the Vercel URL from Step 4
3. Tap the **Share** button (arrow up)
4. Select **Add to Home Screen**
5. Name it "Astronaut Reef" 
6. Tap **Add**

Now he has an app icon on his home screen! Tapping it opens the spaceship simulator.

---

## 🎮 How to Play

- **ACCELERATE / SLOW DOWN**: Control speed
- **TURN LEFT / RIGHT**: Change direction
- **SHIELDS UP**: Protect the ship
- **REVERSE THRUSTER**: Go backward
- **LAUNCH**: Start the sequence!
- **LAND ON MARS**: Begin descent to Mars
- **In Space**: Use **UP/DOWN** to control altitude, **LASER** to fire, **BOOST** for extra speed

---

## 🆘 Troubleshooting

**"Repository not found"?**
- Make sure it's set to **Public**, not Private

**"Build failed"?**
- Check that all files are in the right folders
- Make sure `spaceship_simulator.jsx` is in the `src/` folder

**Not showing on iPad?**
- Clear Safari cache: Settings → Safari → Clear History and Website Data
- Try a hard refresh: Swipe down from top of page
